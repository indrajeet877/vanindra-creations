## 1. The Job in One Paragraph

Every working day, Akarsh finds ~30 well-qualified English-speaking business owners who already use (or clearly need) short-form video, starts ~40–50 genuine, personalised conversations, sends up to 2 free samples or Clip Maps to the best-fit leads, and books **3–5 discovery calls a week** for Smita. He still edits ~4.5 hours a day — so lead gen is **time-boxed**, not open-ended.

### Cold-email setup checklist (do in Week 1)
- [ ] **Never** cold-email from `vanindracreations.com` (protect the main domain) or from any personal Gmail.
- [ ] Buy 1–2 sending domains that clearly belong to us (e.g., `vanindrastudio.com`, `getvanindra.com` — check availability; owner approval). Redirect them to the main site.
- [ ] Create inboxes like `akarsh@[sending-domain]`. Same name and photo everywhere.
- [ ] Set up **SPF, DKIM and DMARC** for each sending domain.
- [ ] Warm up for **2–3 weeks** before any cold sends. Then ramp: 10 → 15 → 20 per inbox per day. Stay **≤ 25–30 per inbox per day**.
- [ ] Plain text. No images. No attachments. **No links in email 1** (sample links come after they reply).
- [ ] Every email: sender's real name, company, a physical postal business address (owner to provide), and a one-line opt-out ("Reply 'no' and I won't follow up").
- [ ] Verify every address before sending (built-in tool or a verifier) — keep bounce rate very low.

| `Budget_Signal` | e.g., "Runs Meta ads", "$2K program" |
| `First_Touch_Date`, `Last_Touch_Date`, `Touch_Count`, `Next_Followup_Date` | Dates / number |
| `Status` | See below |
| `Sample_Type`, `Sample_Link` | Sample / Clip Map / None + link |
| `Call_Date_Their_Time`, `Call_Date_India_Time` | Both, always |
| `Owner` | Akarsh Yadav / Smita Yadav |
| `Handoff_Note` | The hand-off summary (§7) |
| `Plan_Discussed`, `Deal_Value_USD` | Pilot / Spark / Momentum / Full Studio / White-label |
| `Lost_Reason` | Price / Timing / Went with other / No response / Not a fit |
| `Opt_Out` | Y = never contact again |
| `Notes` | Anything else |

**Status values (use exactly these):** `New` → `Warming` → `Contacted` → `Replied-Positive` / `Replied-Neutral` / `Replied-Negative` → `Sample-Sent` → `Call-Booked` → `Call-Done` → `Pilot` → `Won` / `Lost` / `Nurture` · plus `Opt-Out`.

**Follow-up cadence:**
- Email: Day 1 → Day 4 → Day 9 → stop. Move to `Nurture` (one check-in after 60 days with something useful).
- LinkedIn: connect → message on acceptance → Day 5 → Day 12 → stop.
- DMs: Day 1 → Day 4 → Day 10 → stop.
- **Any "no" or "unsubscribe" → `Opt_Out = Y` immediately.**

## 7. Hand-Off to Smita Yadav

**Trigger:** a lead books a call through the booking link, or asks to talk.

1. Booking lands on Smita's calendar (booking tool set to her availability — see Delivery SOP).
2. Akarsh fills `Handoff_Note` in the tracker and posts this in the team WhatsApp group within 2 hours:

```
CALL HANDOFF
Lead: [Full name], [Role], [Company] — [Country]
Call: [their time + zone] = [India time] on [date]
Segment: [S1–S8] | Found via: [channel]
What they do / sell: [one line]
Gap we saw: [one line]
What we sent: [Sample / Clip Map + link]
Their words (if any): "[quote from reply]"
Plan fit guess: [Spark / Momentum / Full Studio / Pilot]
Budget signals: [one line]
Watch-outs: [e.g., health claims, wants guarantees]
```

3. Smita confirms with a reply within 2 hours (or flags a clash).
4. After the call, Smita updates `Status`, `Plan_Discussed`, `Deal_Value_USD`, `Next_Followup_Date`.
5. Akarsh joins calls only if Smita asks (technical / editing-style questions, 10 minutes max).

**Speed rules:** reply to positive replies within **2 business hours** of seeing them; sample delivered within **48 hours** of a "yes"; calls booked within **5 days** of interest.

## 9. Friday 30-Minute Review (Akarsh + Smita, Vandana optional)

1. Reply rate by **channel** and by **segment** → double down on the top 2, pause the worst.
2. Which first line / subject line got the most positive replies → keep the winner, write one new challenger.
3. Sample → call conversion. If low, change the sample style or the follow-up message.
4. Capacity check: if editing load ≥ 40 hours/month signed → start freelance editor recruitment (Delivery SOP §9).
5. Pick next week's 2 focus segments and 2 focus countries.
