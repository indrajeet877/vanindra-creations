# Work archive: October 2026 (internal)

> Source files behind the October 2026 logo, website and pitch-deck work. They are kept here so nothing is lost when a cloud work session ends.
> Internal only: excluded from GitHub Pages (`_config.yml`) and from the public build. Nothing here is approved for public use unless the matching README in `01_Brand_and_Team/` or `04_Outreach_and_Sales_Pipeline/` says so.

| :--- | :--- |

| `pitch_deck/` | Source of the client pitch deck, its render scripts, and the 16:9 PDFs for Google Meet screen-share (English and Hinglish). The phone PDFs are in `04_Outreach_and_Sales_Pipeline/Client_Pitch_Deck_DRAFT/`. |
| `qa_tools/` | The acceptance checker (`verify.js`: rules, Hindi round trip, overflow, features) and the screenshot tools. |
