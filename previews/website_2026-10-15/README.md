# Website design previews (15 Oct 2026)

> **Status:** drafts for the team to compare. Not live. The live homepage (`index.html`) is unchanged.
> These files are excluded from the GitHub Pages site (`_config.yml`) and from `scripts/build_public_site.sh`. Each page also carries `noindex`.

The team liked "Liquid Glass" and asked for 4 variations that are more crystal, more minimal, more focused and cleaner:

| File | Name | In one line | Judges (design / Indian creator on phone / conversion + mobile QA) |
| :--- | :--- | :--- | :--- |
| `v1_crystal.html` | Pure Crystal | The calmest version: almost colourless cut-glass panels, emerald ink, one main button per section | 8.5 / 8 / 7.8 |
| `v2_prism.html` | Prism | Swiss-style minimal and monochrome; the only colour is a thin rainbow "prism" edge on the phone (a nod to Indradhanush) | 8.5 / 8.5 / 8.2 |
| `v3_vision.html` | Vision | Like an Apple Vision Pro app: glass windows with tabs that show one thing at a time; the shortest page | 8 / 7.5 / 7.3 |
| `v4_focus.html` | Focus Story | Like an Apple product page: the phone stays in place while the raw clip turns into a finished Reel as you scroll | 8 / 8.5 / 8.3 |

All 4 beat Liquid Glass in every judge's view. All 4 also pass the automatic checks: names and the one official number, every WhatsApp link going to +91 81128 59437, the Hindi toggle switching back exactly, no sideways scrolling from 320 to 1920 px, dark mode, and the Reel player, AI plan and calculator.

`screens/` has the first-screen preview (computer + phone) and a full phone-length picture of each.
